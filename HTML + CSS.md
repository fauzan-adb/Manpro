# HTML
Objective : Menguasai struktur dan desain website dasar (HTML)
| Key Result        | Description                                                |
|-------------------|------------------------------------------------------------|
| KR1               | Memahami kerangka wajib HTML                               |
| KR2               | Memahami elemen, tag, dan atribut                          |
| KR3               | Memahami tag teks fundamental                              |

Tujuan utama dari objective ini adalah supaya saya bisa membuat website sederhana dengan struktur yang benar dan teks yang tertata rapi.
## 1) Memahami Kerangka Wajib HTML

 Fokus : <!DOCTYPE>, <html, <body, dan <title.

```
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <title>Judul Halaman</title>
  </head>
  <body>
    <h1>Halo Dunia</h1>
  </body>
</html>
```
## 2) Memahami elemen, tag, dan atribut
Maksud: Agar bisa mengenali elemen HTML, tag, dan atributnya untuk membangun halaman web yang benar.

```
<a href="https://www.google.com" target="_blank">Kunjungi Google</a>
<img src="gambar.jpg" alt="Deskripsi Gambar" width="200">
```
Penjelasan:
- a dan img → tag
- href, target, src, alt → atribut

## 3) Memahami tag teks fundamental
Maksud: Agar bisa membuat konten teks dengan tag yang sesuai (judul, paragraf, list, dll).
```
<h1>Judul Utama</h1>
<h2>Subjudul</h2>
<p>Ini paragraf teks</p>
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>
```
Fokus: <h1 sampai <h6, <p, <ul/<ol/<li, <span, <strong, <em, <br.
